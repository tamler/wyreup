# Pro model migration decisions

This branch is not release-ready until authorized provider checks establish runtime schemas, model access, hosting, terms, privacy, output quality and actual billing. In the initial November 19 text phase, twelve sequential synthetic REST requests ran under the approved $1 total, 24-attempt ceiling, with at most six per model and $0.04 reserved per attempt. Incorrect provider contracts can cause refunded runs and count towards the shared daily failure limit.

All six analysis fixtures and four short grammar fixtures passed source-contract and semantic inspection in that phase. The near-cap grammar fixture returned 128 of 130 already-correct sentences despite `finish_reason: stop`. A separately reviewed changed-prompt retest on exactly the same input again returned 128 of 130 sentences with a normal stop. The stronger prompt did not resolve the observed completeness failure. Grammar qualification is stopped; both failed records are retained and Gemma's six-attempt allowance is exhausted. At the end of that phase, speech and the original 4,000-byte grammar case were untested. Mocked tests do not establish runtime quality. Those twelve reservations remain consumed ($0.48); their usage-derived tariff estimates total $0.004278, not verified invoice charges.

Jacob subsequently authorized only the 12 original Aura speech fixtures, preserving the grammar failures and release hold. On source `1c00d0a715a1c4143f5a0caf9c54d16caacdaafb`, all six English/Luna and six Spanish/Aquila requests returned HTTP 200 with MPEG audio. Each complete MP3 decoded successfully; response latencies were 0.948–43.012 seconds within the 60-second deadline. The cumulative ledger now has 24 consumed attempts, six per model, and $0.96 reserved within the existing $1 ceiling. No further inference call is authorized. The speech source-character nominal tariff estimate is $0.068790; the separate conservative full-1,000-character-increment quotes total $0.36. These estimates and reservations are not actual charges; posted charges remain unverified.

Both original normalization-labelled speech inputs contain 125 fullwidth `Ａ` characters: 375 raw UTF-8 bytes and 125 NFKC-normalized bytes. They exercise contraction, not a 500-byte normalized boundary. Their English and Spanish MP3s last 0.576 and 2.904 seconds and are flagged for listening. Neither format/decoder checks nor these REST calls establish spoken completeness, human audio acceptance, the Workers AI JavaScript binding's behavior or funded-credit margin. This was internal compatibility testing, not a comparative vendor benchmark.

The offline grammar candidate requests local JSON edits in the same single Gemma call. Each edit must match a unique span in the original text. Validation covers the full edit list, including overlaps, Unicode grapheme boundaries and output size. Edits preserve line and paragraph breaks. An empty replacement can remove only punctuation or horizontal whitespace. The server rejects ill-formed Unicode input before credit reservation and refunds invalid model edit lists. Structural checks cannot establish whether an edit preserves meaning or whether the provider omitted a necessary correction. Highly repetitive text can yield ambiguous anchors, and unusually large correction sets can exceed the limits. This candidate still needs separately authorized provider qualification, including the original near-cap case and genuine grammar errors.

Credit prices remain provisional: grammar 1, analysis 3, speech 2. A speech request accepts at most 500 raw and NFKC-normalized UTF-8 bytes. At Cloudflare's published $0.03 per 1,000 characters, 500 billable characters cost $0.015. Half of the assumed lowest net revenue for two credits is approximately $0.01614, so headroom is narrow. Provider counting, minimums and rounding are unverified. TTS is limited to English and Spanish; French, Chinese, Japanese and Korean are currently unavailable.

Input limits are reduced: grammar now accepts 4,000 UTF-8 bytes; analysis accepts 34,000 document bytes and 1,500 question bytes. Both raw and NFKC-normalized sizes must fit. Previously the server accepted up to 100,000 UTF-16 code units per text field. These changes and the speech language reduction are breaking consumer behavior; the changeset proposes major bumps for core, CLI and MCP.

`minimax/speech-2.8-turbo` is listed as a third-party model, with a different provider and URL output. It is not silently used; its data handling, terms and price require separate review. No credentials were added.

For grammar, the model prices are $0.10 per million input tokens and $0.30 per million output tokens. Assuming at most one input token per byte, 800 prompt/template tokens, and a 6,144-token completion, the nominal bound is $0.0023232. For analysis, $0.30 input and $1.20 output per million give $0.0182628 for 34,000 document bytes, 1,500 question bytes, 800 overhead and 6,144 completion tokens. Tokenizer, template overhead, reasoning-token accounting and timeout billing remain provider assumptions, not proven maximums.

Both text requests retain a 45-second deadline while permitting up to 6,144 completion tokens. Actual latency and behavior at this cap are unknown; a timed-out request may continue billing after refund. Five failed or pending runs can block all Pro tools for that user until the UTC day resets. The mismatch, response schemas, input options and timeout behavior must be tested with explicit spending authorization before release; do not label the mocks as runtime verification.
